Ejemplos de Código de la Documentación Django:

Estas formas demuestran los siguientes patrones de la documentación:

1. Usar archivos en modelos:

class Car(models.Model):
    name = models.CharField(max_length=255)
    price = models.DecimalField(max_digits=5, decimal_places=2)
    photo = models.ImageField(upload_to="cars")
    specs = models.FileField(upload_to="specs")
2. Usar default_storage directamente:

from django.core.files.storage import default_storage
from django.core.files.base import ContentFile

path = default_storage.save("path/to/file", ContentFile(b"new content"))
3. Guardar archivo externo a FileField:

from pathlib import Path
from django.core.files import File

path = Path("/some/external/specs.pdf")
car = Car.objects.get(name="57 Chevy")
with path.open(mode="rb") as f:
    car.specs = File(f, name=path.name)
    car.save()
