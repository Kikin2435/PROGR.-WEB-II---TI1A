def get_name(request):
    if request.method == "POST":
        form = NameForm(request.POST)  # Formulario vinculado (bound)
        if form.is_valid():
            name = form.cleaned_data['your_name']
            return HttpResponseRedirect("/thanks/")
    else:
        form = NameForm()  # Formulario no vinculado (unbound)
    
    return render(request, "name.html", {"form": form})

📚 Conceptos Clave:

Formularios Bound vs Unbound

Unbound: No tiene datos, se muestra vacío
Bound: Tiene datos enviados, puede validarse

is_valid() y cleaned_data

is_valid(): Ejecuta validación en todos los campos
cleaned_data: Diccionario con datos validados
