🔧 Conceptos Demostrados:

Form vs ModelForm

Form: Creado manualmente, máximo control
ModelForm: Generado desde modelo, menos código

Validación

is_valid(): Ejecuta todas las validaciones
cleaned_data: Datos validados y convertidos

Widgets

TextInput: Campo de texto simple
Textarea: Área de texto multilínea
FileInput: Subida de archivos

Manejo GET/POST

GET: Mostrar formulario vacío
POST: Procesar datos enviados
